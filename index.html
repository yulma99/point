데이터를 불러오는 중이에요…

처음 한 번만 설정해 주세요

  1. data.xlsx를 Google Drive에 올린 뒤 파일을 열고 Google 스프레드시트로 저장합니다.
  2. 스프레드시트 주소의 /d/와 /edit 사이 값을 복사해 Code.gs의 SPREADSHEET_ID에 붙여 넣습니다.
  3. 스프레드시트에서 확장 프로그램 → Apps Script를 열고 Code.gs 전체를 붙여 넣습니다.
  4. 배포 → 새 배포 → 웹 앱에서 실행 사용자는 ‘나’, 액세스 권한은 학생들이 사용할 수 있도록 설정한 뒤 배포합니다. 처음에는 권한을 승인합니다.
  5. 배포 화면의 웹 앱 URL(끝이 /exec)을 script.js의 APPS_SCRIPT_WEB_APP_URL에 붙여 넣고 저장합니다.

로컬에서 index.html을 바로 열 수 있지만, 브라우저 보안 정책 때문에 Apps Script 호출이 차단되면 Chrome에서 파일 접근을 허용하거나 정적 웹 호스팅에 올려 사용해 주세요. URL을 바꾼 뒤에는 새로고침합니다.
